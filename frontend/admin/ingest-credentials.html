How it works

  1. 1

    Issue

    Name the system the token is for — “Acme VMS”, not “north gate camera”. A credential identifies a sender, and may post to any pipeline.

  2. 2

    Hand it over

    The token appears once. Copy it and give it to whoever configures that system. We store only a fingerprint, so nobody — including us — can look it up later.

  3. 3

    Revoke when done

    Revoking deletes the credential. That sender stops being accepted; every other sender keeps working untouched.
