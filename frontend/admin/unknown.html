Merge Identities (Manual)

Manual Merge - When to Use:

Use manual merge when you want to combine two identities that the system hasn't suggested yet, or when you need to merge identities immediately. Important: Always check "Merge Suggestions" first - the system uses graph-based clustering to automatically find clusters of 3+ identities, so it may have already found your duplicates!

NEW: Use MULTI-SELECT mode to merge 3+ identities at once! The system automatically finds the best target identity (most appearances, best quality). Or use "Merge Suggestions" for automatic graph-based clustering.

How to Merge (Step-by-Step):

  1. The "From" identity is already selected (the one you clicked MERGE on)
  2. Find the "To" identity by clicking VIEW on another identity card, or use SEARCH below
  3. Copy the Identity ID from the details modal or search results
  4. Paste it in the "To Identity ID" field below
  5. Click MERGE to combine the identities

Merge Suggestions

How Merge Suggestions Work (New Graph-Based Approach)

The system uses graph-based clustering to automatically find clusters of 3+ identities that are the same person. It analyzes unknown faces daily using:

  1. Pattern Analysis - Checks if identities appear in same cameras, similar times
  2. Face Recognition - Verifies actual face similarity using FAISS
  3. Graph Clustering - Finds connected groups (A=B, B=C → finds A=B=C automatically)

Each suggestion shows a confidence score (0-95%). High (70%+) = usually safe to approve. Medium (50-69%) = review carefully. Low (<50%) = review very carefully.
