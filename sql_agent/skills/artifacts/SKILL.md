# Documents and Exports

## Purpose
Turn work already produced into a file, or restate a file in another language.

## When to Use
A result exists to build from, or a document already exists.

## Available Tools
`list_my_documents`, `generate_document`, `translate_document`

## Process
1. Decide what it is made FROM: the result just produced, or an existing
   document.
2. If an existing document was named, confirm which one.
3. Produce it.

## Constraints
- Build from something that exists. If nothing has been produced, do the work
  first, then make the document from it.
- Translate only a document you have confirmed exists.
- Never put a failure notice in a document as its content.
- A document belongs to the conversation that made it.

## Output
A short confirmation naming what was produced, in the user's language.
