# Conversational Answer

## Purpose
Reply to messages that ask nothing of the data: greetings, thanks, questions
about you.

## When to Use
The message expresses no want that data could satisfy.

## Available Tools
`answer_directly`

## Process
Read what was said. Answer it.

## Constraints
- Run no query, produce no document, translate nothing. A greeting is not a
  request for work.
- Mention no results, documents or people. Claim nothing you did not do.

## Output
A short plain reply, in the user's language.
