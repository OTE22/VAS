#
# Installed by docker/Dockerfile.cpu. Only add a package here if it genuinely
# differs between CPU and GPU; anything else belongs in the base file, or it
# will silently exist on one target and not the other.

-r requirements-base.txt

# ---------------------------------------------------------------------------
# PyTorch — CPU wheels, deliberately.
#
# THE APPLICATION NEVER IMPORTS TORCH. `grep -ri torch --include=*.py` across
# this repository returns nothing. It is here only because
# `sentence-transformers` below requires it, and its entire runtime role is one
# `SentenceTransformer.encode()` call that turns a chatbot question into a
# 384-dim vector for semantic search over query history — a best-effort path
# that already degrades to None when the import fails.
#
# Without this index URL, pip resolves the DEFAULT Linux torch wheel, which is
# the CUDA build: it drags in nvidia-cublas, nvidia-cudnn, nvidia-cufft,
# nvidia-nccl, triton and the rest — roughly 4.5 GB of GPU runtime into an
# image that has no GPU and never calls torch. That was the real state of this
# file; docker/Dockerfile.cpu even carried a BuildKit cache mount to make
# re-downloading it bearable instead of eliminating it.
#
# Face detection and recognition do NOT use torch. They run on ONNX Runtime.
# ---------------------------------------------------------------------------
--extra-index-url https://download.pytorch.org/whl/cpu
torch

# ---------------------------------------------------------------------------
# Inference and vector search — the CPU builds.
# The GPU file pins the CUDA-linked equivalents at a version tied to its base
# image; the two must never be installed together, because both distributions
# provide the same module name.
# ---------------------------------------------------------------------------
onnxruntime==1.23.2
faiss-cpu

# ---------------------------------------------------------------------------
# Query-history semantic search. Pulls torch (above).

sentence-transformers
